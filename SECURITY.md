# Security

Kivact is in early development and has no supported release yet; only the latest commit on `main` is maintained.

Please report vulnerabilities privately by email to Kashiwade <kashiwade@outlook.com>, not in a public issue. Include the affected commit, the platform and the steps to reproduce.

脆弱性は公開の issue ではなく、上のメールアドレスへ非公開で連絡してください。
