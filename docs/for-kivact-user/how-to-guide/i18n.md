# 翻訳と locale を部分木へ渡す

表示言語は `provide_locale`、文言の辞書は `provide_messages` で部分木へ渡します。既定文言を持つ `message` を setup で作り、表示へ渡します。

```rust,no_run
use kivact::prelude::*;
use kivact::i18n::{Locale, Messages, message};
use kivact::view::{provide_locale, provide_messages};

fn translated() -> impl IntoView {
    provide_locale(Locale::new("ja-JP"), || {
        provide_messages(Messages::new().with("profile.save", "保存"), || {
            button(message("profile.save", "Save"))
        })
    })
}
```

locale と辞書には signal や closure も渡せます。内側の辞書は同じ key を上書きし、ない key は外側へ戻ります。辞書を持たない key には、`message` に書いた既定文言を使います。兄弟の部分木には影響しません。

`message_with` は引数の変化も追います。formatter のために毎回新しい `Value` を作らず、setup で作った handle を reactive な表示から読みます。kit の既定文言も同じ key の辞書で置換できます。`Locale::first_day_of_week` のような locale の規則と、アプリ固有の翻訳データは別々に選びます。日付の値は `kivact::i18n::CalendarDate`（年月日。日・月の加減算、曜日、月の長さ）で、calendar と日付入力の部品はどの kit でもこの型を受け渡します。月ごとの週の並びは `CalendarMonth::weeks(first_day_of_week, 0)` が返します。

文字列の組立てと、複数形・日付・数値の完全な国際化エンジンは同じものではありません。必要な formatter の結果を文字列として渡し、locale 切替、長い訳語、RTL の表示をそれぞれ確認します。入力欄の native 編集は改行しない横 scroll の契約であり、翻訳だけで wrap の規則は変わりません。

Pop の日付 UI の追加キーは次のとおりです。年月メニューの月ラベルは `Calendar::month_title` の formatter に各月の1日を渡し、未指定なら `pop.calendar.title` を使います。

| キー | 既定文言 | 用途 |
|---|---|---|
| `pop.calendar.year` | Year | 年 select の名前 |
| `pop.calendar.month` | Month | 月 select の名前 |
| `pop.date.range.pick_start` | Pick a start date | 範囲選択の開始日の案内 |
| `pop.date.range.pick_end` | Pick an end date | 範囲選択の終了日の案内 |
| `pop.date.range.close` | Close | 範囲 popup を閉じるボタン |

kit の文言は `basic.`・`game.`・`pop.`・`creative.` の名前空間に分かれています。標準部品の `dialog.close` や `data_table.select_all` は接頭辞を付けません。同じアプリで複数の kit を使っても、片方の辞書がもう片方の文言へ当たりません。
