# チュートリアル: ToDo アプリを作る

[English](../../en/getting-started/README.md)

このチュートリアルでは、小さな ToDo アプリ **Tasks** を作ります。ページが進むごとに、アプリが少しずつ育ちます。空のウィンドウから始めて、レイアウト、状態、テキスト入力、チェックや削除ができる一覧、スタイル、非同期の読み込みを加え、最後に、仮想バックエンド上で App 全体を操作する自動テストを書きます。各ステップの最後にアプリを実行して、結果を確かめます。

用意するもの:

- Rust のツールチェーン ([rustup](https://rustup.rs) でインストールできます)。Rust を少し知っていると読みやすいですが、Kivact に必要な Rust の知識は、初めて出てきたところで説明します。
- ウィンドウを開けるデスクトップ環境 (Windows、または Wayland / X11 の Linux)。

ページは順番に読み進めてください。各ページには、そのステップが終わった時点の完全なプログラムを載せています。`src/main.rs` にコピーすればそのまま実行できます。

| ステップ | ページ | 作るもの |
| --- | --- | --- |
| 1 | [プロジェクトを作る](01-create-a-project.md) | 文字を表示するウィンドウを開く、空のプロジェクト。 |
| 2 | [コンポーネントとレイアウト](02-components-and-layout.md) | ヘッダーと仮の一覧を、関数に分けたもの。 |
| 3 | [状態](03-state.md) | ボタンで更新される、残りタスク数のカウンター。 |
| 4 | [入力](04-input.md) | テキスト欄と、その内容を読み取る追加ボタン。 |
| 5 | [一覧と条件分岐](05-lists-and-conditions.md) | チェックボックス、削除、空の状態を備えた本物のタスク一覧。 |
| 6 | [スタイルとアクセシビリティ](06-style-and-accessibility.md) | 色、ボタンの種類、アクセシブルな名前、ダークモードのスイッチ。 |
| 7 | [非同期処理](07-async.md) | 保存済みタスクを遅延つきで読み込み、読み込み中とエラーの状態を扱う。 |
| 8 | [テスト](08-testing.md) | 利用者と同じように操作する自動テスト。 |

React／Solid の経験がある場合は、ステップ 2 のセットアップの説明と、ステップ 3 の対応表も確認してください。UI の関数を毎回再実行する代わりに、状態を読む小さなクロージャを更新する流れを学べます。

まずは [プロジェクトを作る](01-create-a-project.md) から始めましょう。
