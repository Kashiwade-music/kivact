# ハウツーガイド

[English](../../en/how-to-guide/README.md)

これらのガイドは、それぞれ Kivact で作るアプリの具体的な問題を 1 つずつ解決します。基本を順に学ぶ[チュートリアル](../getting-started/README.md)を終えていることを前提にしています。業務ツール、ゲーム、クリエイティブツールなど、特定の種類のアプリ向けのテーマとコンポーネントは、[キットのガイド](../../../for-kivact-ui-user/jp/README.md)にあります。

Kivact は開発の初期段階にあり、予告なく破壊的な変更が入ります。これらのガイドにある Rust の例は、リポジトリーのテストですべてコンパイルされています。

React や SolidJS を知っているなら、最初のガイドから始めてください。知っていることを Kivact に対応づけています。

| ガイド | 解決すること |
| --- | --- |
| [React や SolidJS の知識を Kivact に対応づける](coming-from-react-or-solid.md) | 概念の対応表、セットアップが一度だけ実行されるコンポーネント、`dynamic` の match の腕、初心者がつまずく Rust のポイント |
