# アプリを翻訳し、ロケールを設定する

[English](../../en/how-to-guide/i18n.md)

アプリに `Locale` と `Messages` を与えます。自分の文言は `message` で読み、標準コンポーネントの組み込みの文言(「Close」「Select all」「Page 1 of 3」など)も同じ辞書に従います。どちらも、アプリ全体、1 つの部分木、あるいは実行中の切り替えで差し替えられます。

Kivact が運ぶのは言語と文言だけです。翻訳ファイル、複数形の規則、日付や数値の書式は持っていません。翻訳をどう読み込むかはあなたが決め、整形済みの値を渡します。

## 最短で動く翻訳

```rust,no_run
use kivact::i18n::{Locale, Messages};
use kivact::prelude::*;

fn app() -> impl IntoView {
    column((
        text(message("greeting", "Hello")),
        dialog("設定", signal(true)).content(|| text("...")),
    ))
}

fn main() -> kivact::Result<()> {
    let ja = Messages::new()
        .with("greeting", "こんにちは")
        .with("dialog.close", "閉じる");

    App::new("Notes")
        .locale(Locale::new("ja-JP"))
        .messages(ja)
        .run(app)
}
```

- `Locale::new("ja-JP")` は BCP 47 のタグです。`App::locale` がなければ、アプリはシステムのロケールを使い(システムが何も示さなければ `en-US`)、実行中にユーザーが変更するとそれに追従します。`App::locale` を指定すると、システムがどうであれ、そのロケールを保ちます。
- `Messages::new().with(key, text)` は、置き換え用の辞書です。キーは `&'static str` です。
- `message(key, default)` は `Value<String>` を返します。`key` に対する辞書の文言、なければ `default` です。そのまま `text(..)`、`name(..)`、`placeholder(..)` に渡せます。default は翻訳されていないアプリが表示する文言なので、ソースコードの言語で書いてください。
- コンポーネントも同じ辞書から文言を引きます。上の `"dialog.close"` がダイアログの閉じるボタンの名前を変えるのはそのためです。

`message` は小さなリアクティブな値を作るので、ハンドラーの中ではなく、セットアップ中(コンポーネントの関数の中)で呼びます。

## 値を含む文言

`message_with(key, default, args)` は `{name}` のプレースホルダーを埋めます。値をどこに置くかは翻訳側が決めるので、どの言語でも自然な語順を保てます。

```rust,no_run
use kivact::i18n::message_with;
use kivact::prelude::*;

fn selection(selected: Signal<Vec<u32>>) -> impl IntoView {
    // 英語: "3 selected"。日本語の辞書: "{count} 件選択中"。
    let label = message_with("selection.count", "{count} selected", move || {
        [("count", selected.with(Vec::len).to_string())]
    });
    text(label)
}

fn main() -> kivact::Result<()> {
    App::new("Selection").run(|| selection(signal(vec![1, 2, 3])))
}
```

- `args` のクロージャは、読んだ値が変わると再実行されるので、文言はシグナルに追従します。
- クロージャが値を返さない `{name}` は、書いたまま残ります。
- 複数形は別々のキーにします。コードの側で選び、適切なキーを読みます。`"items.one"` と `"items.other"` に、それぞれ `"{count} item"` と `"{count} items"` を割り当てます。
- 値は文字列です。数値や日付の整形は(好きなクレートで)自分で行い、結果を渡してください。

## 実行中に言語を切り替える

`provide_locale` と `provide_messages` は、シグナル、memo、クロージャを受け取ります。それが変わると、下にあるすべての `message` と標準コンポーネントが、作り直されることなく追従します。

```rust,test_harness
use kivact::i18n::{Locale, Messages, message_with};
use kivact::prelude::*;
use kivact::i18n::{provide_locale, provide_messages};

fn page(japanese: Signal<bool>) -> impl IntoView {
    let greeting = message("greeting", "Hello");
    let items = message_with("items.count", "{count} items", || [("count", "3".to_owned())]);
    let open = signal(false);

    column((
        text(greeting),
        text(items),
        button("Open dialog").on_press(move || open.set(true)),
        button("Switch language").on_press(move || japanese.update(|j| *j = !*j)),
        dialog("Settings", open).content(|| text("...")),
    ))
    .style(style().gap(8).padding(16))
}

fn app() -> impl IntoView {
    let japanese = signal(false);
    let locale = memo(move || Locale::new(if japanese.get() { "ja-JP" } else { "en-US" }));
    let messages = memo(move || {
        if japanese.get() {
            Messages::new()
                .with("greeting", "こんにちは")
                .with("items.count", "{count} 件")
                .with("dialog.close", "閉じる")
        } else {
            Messages::new()
        }
    });

    provide_locale(locale, move || {
        provide_messages(messages, move || page(japanese))
    })
}

fn main() -> kivact::Result<()> {
    App::new("Languages").run(app)
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn switching_the_dictionary_retranslates_texts_and_components() {
        let screen = kivact::test::render(app);
        screen.get_by_text("Hello");
        screen.get_by_text("3 items");

        screen.get_by_role(Role::Button, "Open dialog").click();
        screen.get_by_role(Role::Button, "Close");
        screen.press_key(Key::Escape);
        screen.get_by_role(Role::Button, "Switch language").click();

        screen.get_by_text("こんにちは");
        screen.get_by_text("3 件");
        screen.get_by_role(Role::Button, "Open dialog").click();
        screen.get_by_role(Role::Button, "閉じる");
    }
}
```

現在のロケールは `kivact::i18n::use_locale()` で読みます。`Value<Locale>` を返し、`locale.get().language()` は `ja-JP` なら `"ja"`、`locale.get().first_day_of_week()` はその地域のカレンダーの最初の列の曜日です。

## 画面の一部だけを翻訳する

`provide_locale` と `provide_messages` は、1 つの部分木を包むこともできます。兄弟の部分木は、上から引き継いだ設定のままです。部分木の messages は外側の messages の**上に重なります**。部分木が設定したキーは置き換わり、ほかのキーは外側の文言を保ちます。

```rust,no_run
use kivact::i18n::{Locale, Messages};
use kivact::prelude::*;
use kivact::i18n::{provide_locale, provide_messages};

fn quote() -> impl IntoView {
    column((
        text(message("quote.label", "Quote")),
        // この部分だけフランス語。
        provide_locale(Locale::new("fr-FR"), || {
            provide_messages(Messages::new().with("quote.label", "Citation"), || {
                text(message("quote.label", "Quote"))
            })
        }),
    ))
}

fn main() -> kivact::Result<()> {
    App::new("Quote").run(quote)
}
```

`provide_locale` が変えるのはロケールだけ、`provide_messages` が変えるのは文言だけです。両方変えるときは組み合わせます。

## 標準コンポーネントの文言を置き換える

標準コンポーネントは、`<コンポーネント>.<用途>` という安定したキーと英語の default で `message` を通して文言を読みます。アプリの messages にそのキーを設定するとあらゆる場所で置き換わり、部分木に設定するとそこだけが置き換わります。

| キー | 既定 | 使われる場所 |
| --- | --- | --- |
| `dialog.close` | Close | ダイアログの閉じるボタン |
| `toast.close` | Close | トーストの閉じるボタン |
| `select.placeholder` | Select… | 何も選んでいない `select` |
| `switch.on`、`switch.off` | ON、OFF | `switch` の隣の文言 |
| `slider.minimum`、`slider.maximum` | Minimum、Maximum | `range_slider` のつまみ |
| `data_table.filter`、`.empty`、`.previous`、`.next`、`.select_all` | Filter…、No results found.、Previous、Next、Select all | `data_table` |
| `data_table.page`、`data_table.select_named` | Page {page} of {pages}、Select {row} | `data_table`(値を含む) |

これは一部であり、全体ではありません。各コンポーネントの rustdoc にキーが載っています(`cargo doc -p kivact-ui --open`)。キットの独自のキーには、キット名の接頭辞(`basic.`、`pop.`、`game.`、`creative.`)が付くので、1 つのアプリで 2 つのキットを使っても、片方の辞書がもう片方を上書きすることはありません。キットごとのキーは[キット一覧](../../../for-kivact-ui-user/jp/README.md)に載っています。

翻訳しない文言は英語の default のままなので、部分的な辞書でも安全です。訳し漏れを見つけるには、デバッグビルドで言語を切り替え、英語のまま残っているものを探します。

## 右から左へ書く文字

`provide_direction` は部分木を右から左へ読むものとして指定します。向きに依存するコンポーネントは、セットアップ中に一度だけそれを読みます。横向きの `slider` は右から始まり、矢印キーも反転します。横向きの `radio_group` の矢印キーも同様です。

```rust,no_run
use kivact::prelude::*;
use kivact::style::Direction;
use kivact::view::{ReadingDirection, provide_direction};

fn arabic_settings() -> impl IntoView {
    provide_direction(ReadingDirection::Rtl, || {
        column((
            slider("音量", signal(30.0)),
            // レイアウトは自動では反転しない。row は自分で反転する。
            row((text("名前"), text("Ann"))).style(style().direction(Direction::RowReverse)),
        ))
        .style(style().gap(8))
    })
}

fn main() -> kivact::Result<()> {
    App::new("RTL").run(arabic_settings)
}
```

Kivact は、あなたのレイアウトも、標準コンポーネントの row も反転しません。必要な row は `Direction::RowReverse` で反転し、自分のコンポーネントでは `kivact::view::use_direction().get()` をセットアップ中に一度読んで判断します。

## 入力メソッドとフォント

- 入力メソッド(IME)は、`text_input` と `text_area` で何も設定せずに動きます。変換中の文字はバインディングに書かれず、確定した文字だけが書かれます。ロケールはこれを変えません。
- 文字のレイアウトは翻訳で変わりません。長い訳文は、ほかの文字と同じように折り返すので、長い文字列でレイアウトを確認してください。`text_input` は、言語に関係なく、横にスクロールする 1 行です。
- 言語によっては、すべてのシステムにはないフォントが必要です。フォントを登録して、`font_family` のリストにその名前を書きます。[画像とフォント](images-and-fonts.md)を参照してください。
