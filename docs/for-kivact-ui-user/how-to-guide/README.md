# Kit 別の目的別ガイド

標準部品の操作は共通の `kivact::ui` と interaction、外観は kit のテーマ、分野固有の表示は各 kit の部品を使います。

| Kit | 目的 |
|---|---|
| [Basic](basic.md) | テーマの切替、overlay、表とグラフ、フォーム |
| [Pop](pop.md) | 検証を持つフォームと業務画面 |
| [Game](game.md) | タブ付きの操作パネル |
| [Creative](creative.md) | 同じ数値を複数の編集部品へ結ぶ |

[共通ガイド](../../for-kivact-user/how-to-guide/README.md)の入力、一覧、表、dialog、テーマもそのまま使えます。独自のデザインシステムを作るときは [部品作者ガイド](../../for-component-author/README.md)へ進みます。
