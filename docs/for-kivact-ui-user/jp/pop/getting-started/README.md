# チュートリアル: Pop キットでサインアップフォームを作る

[English](../../../en/pop/getting-started/README.md)

Pop (`kivact-ui-pop`) は、落ち着いた配色で情報を密に並べる業務アプリ向けの Kivact キットです。このチュートリアルでは、テキスト欄、プランの切り替え、2 つの日付、作成ボタンを備えたサインアップフォーム **New account** を作ります。ページごとにアプリを少しずつ育て、各ステップで実行して結果を確かめます。

必要なもの:

- コアのチュートリアル [To-do アプリを作る](../../../../for-kivact-user/jp/getting-started/README.md)、または同等の経験。`signal`、`column`、`text`、`button` を使ったことがあれば大丈夫です。
- Rust のツールチェーンと、ウィンドウを開けるデスクトップ環境（Windows、または Wayland か X11 の Linux）。

各ページには、そのステップ終了時点の完全なプログラムを載せています。`src/main.rs` にそのまま貼り付けて実行できます。

| ステップ | ページ | 作るもの |
| --- | --- | --- |
| 1 | [キットを導入する](01-set-up-the-kit.md) | Pop の見た目で、名前欄とボタンを持つウィンドウ。 |
| 2 | [フォームを組み立てる](02-build-the-form.md) | ヒント付きの名前欄とメール欄、プランの切り替え、キット色のボタン。 |
| 3 | [検証して送信する](03-validate-and-submit.md) | 日付欄、エラーメッセージ、成功メッセージ、そしてテスト。 |

始める前にキットの全体像を見たいときは、リポジトリのチェックアウトからカタログを起動します。

```text
cargo run -p kivact-ui-pop-catalog
```

まず [キットを導入する](01-set-up-the-kit.md) へ進みましょう。
