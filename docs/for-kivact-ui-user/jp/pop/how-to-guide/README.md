# Pop 作業別ガイド

[English](../../../en/pop/how-to-guide/README.md)

Pop キット（`kivact-ui-pop`）で 1 つの作業を片づけるためのガイド集です。[Pop のチュートリアル](../getting-started/README.md) を終えていることを前提にしています。コンポーネントとオプションの全一覧は `cargo doc -p kivact-ui-pop --open` で確認できます。

| ガイド | 目的 |
| --- | --- |
| [Pop のテーマとトークンを設定する](theme-and-tokens.md) | テーマを入れ、ライトとダークを切り替え、色とフォントを変え、トークンを読む。 |
| [日付と期間を選ばせる](dates-and-calendars.md) | 日付や期間を入力させ、イベント付きのカレンダーを表示する。 |
| [業務画面で数値・状態・レコードを見せる](status-and-figures.md) | 統計カード、レコード一覧、バッジ、詳細の行で概要画面を作る。 |
| [テーブルで行を表示する](tables.md) | 検索・並べ替え・選択・ページ送り・一括操作の付いたレコード表示。 |
| [メッセージと通知を出す](messages-and-notifications.md) | アラート、トースト、通知履歴、読み込み中・空のプレースホルダーを使う。 |
