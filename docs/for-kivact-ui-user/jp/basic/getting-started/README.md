# チュートリアル: Basic キットで設定画面を作る

[English](../../../en/basic/getting-started/README.md)

`kivact-ui-basic` は、Kivact の中立で汎用的なキットです。shadcn/ui の「Lyra」プリセット（Neutral の配色、角の丸みなし、12 px の文字、Lucide のアイコン）の見た目に従います。このチュートリアルでは「設定」画面というひとつのアプリを作り、ステップごとに育てていきます。やり直しはありません。各ページは、前のページのプログラムの続きです。

完成すると、ライトとダークを切り替えられるテーマ、入力欄とスイッチを並べた 2 枚のカード、保存後のトースト、確認ダイアログ、そしてテストを備えたウィンドウができあがります。

## はじめる前に

[コアのチュートリアル](../../../../for-kivact-user/jp/getting-started/README.md)を終えるか、少なくとも読んでください。signal、関数としてのコンポーネント、レイアウトとスタイルを説明しており、このチュートリアルはそれらを改めて説明せずに使います。また、リポジトリが固定している Rust ツールチェイン（1.98.1、edition 2024）が必要です。対象のプラットフォームは Windows と Linux（Wayland または X11）です。

Kivact は開発の初期段階にあり、API は予告なく変わります。各キットの現状は[キットの一覧](../../README.md)を参照してください。

始める前にキットに何があるかを見たいときは、リポジトリをクローンしてカタログを実行します。カタログは、すべてのコンポーネントとそのソースコードを並べて表示するウィンドウです。

```text
cargo run -p kivact-ui-basic-catalog
```
