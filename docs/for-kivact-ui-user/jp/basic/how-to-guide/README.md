# how-to ガイド: Basic キット

[English](../../../en/basic/how-to-guide/README.md)

これらのガイドは、`kivact-ui-basic` で 1 つずつ目的を解決します。各ページは、まず最短で動く解決策を示し、そのあとでバリエーションと詳細を扱います。[チュートリアル](../getting-started/README.md)を終えていることを前提にしています。API の全体は `cargo doc -p kivact-ui-basic --open` で、すべてのコンポーネントとそのソースは、リポジトリのクローンで `cargo run -p kivact-ui-basic-catalog` を実行すると見られます。

| ガイド | 目的 |
|---|---|
| [テーマを適用、切り替え、カスタマイズする](theme-and-tokens.md) | アプリに Basic の見た目を与え、実行中にライトとダークを切り替え、色を読み書きし、recipe を調整し、フォントを選び、Lucide のアイコンを使う |
| [ダイアログ、シート、ポップオーバー、メニュー、トーストを出す](overlays.md) | ダイアログ、確認、シート、ドロワー、ポップオーバー、ホバーカード、メニュー、トーストをページの上に重ねる |
| [ナビゲーションを作る](navigation.md) | サイドバーのシェル、タブ、パンくず、メニューバー、ナビゲーションメニュー、ページネーションを追加する |
| [データを表示する](data-display.md) | 表、並べ替えできるデータテーブル、グラフ、バッジ、アバター、コードブロックを見せる |
| [ズームできる軸の上にプロットを描く](plot.md) | 線形または対数の軸に折れ線、点、ステム、ヒストグラム、ヒートマップを描き、ユーザーが範囲をズーム、パン、リセットできるようにする |
| [フォームを作る](forms.md) | field にラベルを付けて検証し、まとめ、入力欄に付け足しを加え、コンボボックス、日付ピッカー、カレンダー、ワンタイムコードを使う |
