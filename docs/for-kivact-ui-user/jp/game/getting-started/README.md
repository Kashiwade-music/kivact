# チュートリアル: Game キットでロードアウト画面を作る

[English](../../../en/game/getting-started/README.md)

Game (`kivact-ui-game`) は、ゲーム風の操作パネルや HUD 向けの Kivact キットです。直線的な角、斜めのボタン、区切りのあるメーター、密度の高いレイアウトが特徴です。このチュートリアルでは、出撃前にプレイヤーが武器と防具を選ぶ画面 **Loadout** を作ります。ページごとにアプリを少しずつ育て、各ステップで実行して結果を確かめます。

必要なもの:

- コアのチュートリアル [To-do アプリを作る](../../../../for-kivact-user/jp/getting-started/README.md)、または同等の経験。`signal`、`memo`、`column`、`text`、`button` を使ったことがあれば大丈夫です。
- Rust のツールチェーンと、ウィンドウを開けるデスクトップ環境（Windows、または Wayland か X11 の Linux）。

各ページには、そのステップ終了時点の完全なプログラムを載せています。`src/main.rs` にそのまま貼り付けて実行できます。

| ステップ | ページ | 作るもの |
| --- | --- | --- |
| 1 | [キットを導入する](01-set-up-the-kit.md) | Game の見た目で、枠付きのパネルと斜めのボタンを持つウィンドウ。 |
| 2 | [パネルを組み立てる](02-build-the-panel.md) | 見出し、状態バッジ、メーター、それらを変えるボタン。 |
| 3 | [タブとアイテム](03-tabs-and-items.md) | 武器と防具のタブ、アイテム一覧、装備ボタン、そしてテスト。 |

始める前にキットの全体像を見たいときは、リポジトリのチェックアウトからカタログを起動します。

```text
cargo run -p kivact-ui-game-catalog
```

まず [キットを導入する](01-set-up-the-kit.md) へ進みましょう。
