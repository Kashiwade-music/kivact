# Creative キットのハウツーガイド

[English](../../../en/creative/how-to-guide/README.md)

Creative キット（`kivact-ui-creative`）の目的別ガイドです。各ページは最短で動く解決方法から始まり、そのあとにバリエーションと、つまずきやすい細部を説明します。[チュートリアル](../getting-started/README.md)を終えていることを前提にしています。API の全体は rustdoc（`cargo doc -p kivact-ui-creative --open`）で、すべての部品の動作はカタログ（`cargo run -p kivact-ui-creative-catalog`）で確認できます。

| ガイド | 内容 |
|--------|------|
| [Creative キットのテーマ・フォント・アイコンを設定する](theme-and-icons.md) | テーマの適用、アクセントと密度の選択、ライト/ダークの切り替え、自分のフォント、アイコンの追加、キットの文言の翻訳 |
| [ノブとフェーダーの表示・写像・微調整](knobs-and-faders.md) | 値の文字列と解析、線形・対数・skewed・custom の写像、位置のステップ、ドラッグ距離、ノブでの入力、スクラブの修飾キー、ホイールの積み上げ |
| [タイムライン・ドープシート・グラフ・アレンジメントを編集する](timeline-and-arrangement.md) | クリップ・キー・曲線・トラックの表示、エディタからの要求の受け入れと拒否、アプリが持つ再生ヘッド、トランスポートとミキサーの部品 |
| [ノードグラフでノードをつなぐ](node-graph.md) | 型付きソケット、リンク、ノードのパラメータとプレビュー、接続規則、ジェスチャー単位の取り消し |
| [色・イージング曲線・グラデーションを編集する](color-curves-and-gradients.md) | カラーポップアップとホイール、プレビュー付きの 3 次ベジェイージング、グラデーションのストップ、編集ごとに 1 つの取り消し手順 |
| [アプリが描いたフレームを表示する](show-app-rendered-images.md) | 自分のピクセルをズーム・パン・オーバーレイ・ポインター座標付きで表示、ワーカースレッドでの描画、実験的な GPU フレーム |
| [ドック・パネルグループ・アウトライナーを作る](panels-docks-and-outliners.md) | アプリが持つドックのレイアウト、アウトライナーの名前変更・親の変更・制限、インスペクターの区画、検索できるピッカー |
