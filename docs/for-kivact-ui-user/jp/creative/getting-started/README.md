# Creative キットを始める

[English](../../../en/creative/getting-started/README.md)

Creative キット（`kivact-ui-creative`）は、クリエイティブ編集ツール向けの部品を集めたキットです。密度の高い数値フィールド、カラーホイール、イージング曲線、アウトライナー、ドック、タイムライン、ノードグラフ、ビューポートなどがそろっています。このチュートリアルでは、架空のレイヤーエディタの「インスペクター」を作ります。レイヤーの数値・色・イージング曲線をパネルで編集できるようにし、そのパネルをレイヤーのアウトライナーと並べてドックに置きます。

先に Kivact の基本（シグナル、関数としてのコンポーネント、アプリの起動）を知っておく必要があります。まだの場合は、先に[コアのチュートリアル](../../../../for-kivact-user/jp/getting-started/README.md)を終わらせてください。

最後まで進むと、2 つのパネルを持つドックのウィンドウと、それを操作するテストができます。また、キットが受け持つこと（描画とジェスチャー）と、アプリが受け持つこと（データの所有）の分け方も分かります。

| ステップ | 作るもの | 学ぶこと |
|----------|----------|----------|
| [1. キットを設定する](01-set-up-the-kit.md) | テーマを適用したウィンドウと数値フィールド 1 つ | 依存関係の追加、キットのテーマ、`panel`・`property_row`・`number` |
| [2. 値を編集する](02-edit-values.md) | 位置・不透明度・色・イージングのエディタと元に戻すボタン | 1 つの値を複数のエディタで編集、`EditPhase`、`color_popup`、`bezier_curve` |
| [3. ドックに置く](03-dock-and-outliner.md) | レイヤーのアウトライナーとインスペクターを並べたドック、テスト | `dock`・`outliner`、共有する選択、テスト |

始める前にキットの全体像を見たい場合は、Kivact のリポジトリを checkout して、カタログを起動してください。

```text
cargo run -p kivact-ui-creative-catalog
```

終わったら、[ハウツーガイド](../how-to-guide/README.md)でタイムライン、ノードグラフ、曲線とグラデーション、アプリが描いた画像の表示などを確認できます。
