# Game how-to guides

[日本語](../../../jp/game/how-to-guide/README.md)

Each guide solves one task with the Game kit (`kivact-ui-game`). They assume you
have finished the [Game tutorial](../getting-started/README.md). For the full
list of components and options, run `cargo doc -p kivact-ui-game --open`.

| Guide | Goal |
| --- | --- |
| [Set the theme and density](theme-and-density.md) | Install the theme, choose light or dark and compact density, change colors and fonts. |
| [Show items in lists and trees](item-lists-and-selection.md) | Show items the player picks from, with the app owning the items and the selection. |
| [Show meters and status](meters-and-status.md) | Show health bars, key figures, status labels, property sheets and event logs. |
| [Offer choices and quick actions](choices-and-toolbars.md) | Use segments, cards and vertical navigation to choose, and toolbars for quick actions. |
| [Add effects and depth](effects-and-depth.md) | Build a pointer parallax, 3D tilt cards, turning panels, glitch filters, shader backgrounds, timed boot logs and scroll headers in the kit's colors and corners. |
